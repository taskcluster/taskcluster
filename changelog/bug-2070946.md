taskcluster-proxy no longer admits connections from root (or SYSTEM on Windows) when started with `--allowed-user`. A new `--credentials-stdin` option lets generic worker refresh credentials over the proxy's stdin instead of the `/credentials` endpoint, which is disabled in that mode. With `--credentials-stdin`, the proxy also exits when its stdin is closed, so it doesn't outlive the generic worker process that launched it. Generic worker now uses this option.

**Worker deployers must upgrade taskcluster-proxy and generic worker together.**
