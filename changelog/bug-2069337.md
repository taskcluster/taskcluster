D2G: named/registry docker images are always re-pulled and `docker run` pins them by digest, so a poisoned local tag cannot persist across tasks. As with image artifacts, payloads converted by `taskcluster d2g` now show the `__D2G_IMAGE_ID__` placeholder instead of the image name in the `docker run` command; generic-worker substitutes the pulled image ID at runtime.
